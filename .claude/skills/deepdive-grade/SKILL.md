# 정리 채점

## 순서

1. `scripts/grade-snapshot.sh dayNN-topic`을 실행하고, 해당 일차 README를 **매번 파일에서 다시 읽는다**(`sed -n '/^## 3\. 정리/,$p'`). `SAME`이면 채점하지 말고 편집기에서 저장했는지 묻는다(출력의 저장 시각을 함께 알려 준다). `FIRST`·`CHANGED`면 채점하고, 출력의 "지난번 N점"을 제목 괄호에 쓴다.
2. 같은 README의 `## 1. 질문`(핵심 질문)과 2번 섹션의 실험 결과를 기준으로 [rubric.md](./rubric.md)에 따라 채점한다.
3. 출력 형식
   - `## 채점 결과: X / 10 (지난번 Y점)`. 첫 채점이면 괄호를 뺀다.
   - 항목별 표: `| 항목 | 점수 | 한 줄 평 |`. 정리 섹션의 소제목마다 한 행, 남은 의문은 가산점 행.
   - 감점 항목마다: 사용자 문장 인용 → 무엇이 틀렸거나 빠졌는지 → 고친 예시.
   - 남은 의문에 대한 답: 비유 하나 + 표나 짧은 코드 하나. 실험 결과를 근거로 든다.
   - 감점은 아니지만 짚을 점(예: Claude 문장을 그대로 옮김)은 따로 적는다.
4. 사용자 문장은 고치지 않는다. 서식 수정은 사용자가 요청할 때만 한다.
5. 마지막 줄: 무엇만 고치면 끝인지 + 다음 행동(재채점 또는 커밋) 제안.
6. 채점을 마치면 `scripts/grade-snapshot.sh dayNN-topic --save 점수`로 기록한다.
