# 채점 기준 (10점)

정리 섹션의 소제목(보통 3개)에 점수를 나눈다. 3개면 각 3점, 남은 의문 최대 +1점.

| 기준 | 만점 조건 | 대표 감점 |
| --- | --- | --- |
| 정확성 | 틀린 문장이 없다 | 사실 오류, 서로 다른 것을 같다고 씀 |
| 메커니즘 | "무엇"뿐 아니라 "어떻게/왜"가 있다 | 필드·용어만 나열 |
| 근거 | 그날 실험 결과(출력)와 연결된다 | 실험에서 확인한 차이가 빠짐 |
| 일관성 | 섹션끼리 충돌하지 않는다 | 한 곳에선 "매번 버림", 다른 곳에선 "유지됨" |
| 서식 | 목록 레벨·코드 표기가 맞다 | 들여쓰기 오류(-0.5) |

- 핵심 질문 하나에 답이 아예 없으면 그 항목 0점.
- 남은 의문: 구체적인 질문이면 +0.5, 스스로 가설까지 적었으면 +1.
- 점수는 0.5 단위.
