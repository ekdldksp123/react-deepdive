# 일차 폴더 만들기

입력: 사용자가 붙여 넣은 계획(제목, 오늘 할 일, 핵심 질문, 시작 포인트, 루틴).

## 순서

1. 직전 일차 폴더를 열어 README 구조와 파일 구성을 확인한다. 기준은 `day01-jsx-createElement/`.
2. 폴더 `dayNN-<영문-주제>/`를 만든다(NN은 두 자리).
3. README.md
   - 제목: 계획의 첫 줄 그대로 (`# N일차 / 56 — 주제 (날짜)`)
   - `오늘 할 일:` 한 줄
   - `## 1. 질문 (5분)`: 핵심 질문을 체크리스트로 + `- [ ] (내 질문)`
   - `## 2. 읽기·구현 (40분)`: 시작 포인트를 실험 단계로 나눈다. 각 실험마다 실행 명령과 "보면서 확인할 것" 질문 목록(답은 비워 둔다).
   - `## 3. 정리 (15분, 설명하듯)`: 핵심 질문에 대응하는 빈 소제목 + `### 오늘 새로 안 것 / 남은 의문`. 내용은 사용자가 쓴다. 절대 채우지 않는다.
4. 실험 스크립트 `01-*.js`, `02-*.js`: 실제로 돌려서 출력이 나오는지 확인한다. 출력은 README에 넣지 않는다(사용자가 실행 후 요청하면 넣는다).
5. 구현 과제가 있으면 TODO 스텁 + `*.test.js`(`node:test`). 스텁은 구현하지 않는다. 테스트는 스크래치패드의 참조 구현으로 전부 통과하는지 확인한다(참조 구현은 레포에 넣지 않는다).
6. package.json에 `dayNN:*` 스크립트, 루트 README 진행 표에 한 줄 추가.
7. `npm test`로 새 테스트가 "not implemented"로만 실패하는지 확인한다.
8. 커밋은 사용자가 요청할 때만.

## 마무리 보고

만든 파일, 실행 명령, 실험에서 눈여겨볼 점(답이 아니라 관찰 포인트)만 알린다.
